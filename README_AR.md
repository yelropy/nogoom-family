# نجوم البيت — موقع عائلي سحابي

موقع باللغة العربية للأب والأم وطفلين (13 و9 سنوات)، متصل بـ Firebase Authentication + Cloud Firestore، ويمكن نشره مجاناً على GitHub Pages بحسب حدود الاستخدام في الخدمات. يستعمل قاعدة بيانات واحدة متزامنة فورياً بين الأجهزة.

## أولاً: محتويات الملفات

- `index.html`: واجهة الموقع.
- `style.css`: التصميم الهادئ الأصلي غير الطفولي.
- `app.js`: الحسابات، الإنجازات، المكافآت، تقارير الأسبوع والشهر، التوقيعات والمزامنة.
- `firebase-config.js`: بيانات مشروعك الخاص؛ مطلوب إكمالها.
- `firestore.rules`: قواعد الصلاحيات؛ **يجب نشرها** في Firestore قبل الاستخدام.

## ثانياً: إنشاء مشروع Firebase

1. افتح https://console.firebase.google.com/ وأنشئ مشروعاً جديداً باسم مثلاً `nojom-family`.
2. من **Build > Authentication > Sign-in method** فعّل **Email/Password**.
3. من **Build > Firestore Database** أنشئ قاعدة Cloud Firestore (اختر منطقة قريبة، وتجنب قواعد Test Mode المفتوحة؛ سنضع القواعد المقيدة).
4. من **Project settings > General > Your apps** أضف **Web app**، وانسخ `firebaseConfig` إلى `firebase-config.js`.
5. عدّل `familyId` في `firebase-config.js` إلى معرّف خاص من اختيارك، مثلاً `myfamily-6r4v...`، بدون مسافات أو شرطات مائلة. استخدم القيمة نفسها لاحقاً في Firestore.
6. من Firestore > Rules الصق محتويات `firestore.rules` بالكامل ثم اضغط **Publish**. **لا** تستعمل `allow read, write: if true`.

## ثالثاً: إنشاء الحسابات الأربعة وتعيين الأدوار

1. في Firebase **Authentication > Users > Add user** أنشئ أربعة مستخدمين مختلفين، أحدهم الأب، والثاني الأم، والثالث للطفل 13 سنة، والرابع للطفل 9 سنوات. احتفظ بـ UID لكل مستخدم.
2. في Firestore > Data أنشئ المسار التالي (مع استبدال `FAMILY_ID` بالمعرّف الخاص في `firebase-config.js`):

   `families / FAMILY_ID / members / UID_الأب`

   وأنشئ الحقول الآتية للمستند:

   - `name` (string): `الأب`
   - `role` (string): `father`

3. أنشئ مستند العضو للأم بالطريقة نفسها، مستند ID الخاص به يساوي UID حساب الأم، وحقول `name: الأم` و `role: mother`.
4. أنشئ مستند العضو للطفل الأكبر (document ID = UID الخاص به): `name: الطفل الأكبر` و `role: child` و `kidId: a`.
5. أنشئ مستند العضو للطفل الأصغر: `name: الطفل الأصغر` و `role: child` و `kidId: b`.

> **هام:** لا تجعل الطفل يملك كلمة مرور حساب الأب أو الأم. حساب الطفل 9 سنوات ينبغي إنشاؤه وإدارته تحت إشراف أحد الوالدين، مع الالتزام بشروط العمر والاستخدام لدى مزود الخدمة. يمكن الاستعاضة عن دخوله باستخدام أحد الوالدين معه إذا لزم.

## رابعاً: نشر الموقع على GitHub Pages

1. سجّل الدخول إلى https://github.com/ وأنشئ Repository جديداً، مثلاً `nojom-family`. استخدم مستودعاً عاماً إذا كنت تعتمد GitHub Pages المجاني الذي يتطلب ذلك لحسابك. **لا تضع كلمات المرور أو مفاتيح الإدارة أو بيانات عائلية في المستودع**.
2. ارفع الملفات: `index.html`, `style.css`, `app.js`, `firebase-config.js`. الملف `firestore.rules` يُنشر من Firebase Console ولا يحتاج أن يكون في الموقع.
3. في GitHub افتح **Settings > Pages > Build and deployment** ثم اختر **Deploy from a branch** و `main` و `/ (root)` ثم Save.
4. سيظهر رابط شبيه بـ `https://USERNAME.github.io/nojom-family/`.
5. من Firebase Authentication > Settings > Authorized domains أضف `USERNAME.github.io` (اسم النطاق فقط، بدون https أو اسم المستودع). النطاق يجب أن يكون مسجلاً للسماح بتسجيل الدخول.
6. افتح الرابط على موبايل الأب والأم وتابلت الأطفال، وسجّل الدخول لكل حساب. ستظهر التحديثات المباشرة لكل المسموح لهم.

**تنبيه الخصوصية:** ملفات JavaScript وبيانات الاتصال العادية بـ Firebase تكون علنية لزوار الموقع، ولذلك **القواعد المقيدة وحسابات المستخدمين هي الحماية الفعلية**. لا تضع كلمات مرور المستخدمين في أي ملف؛ موقع GitHub Pages ليس خاصاً بمجرد عدم مشاركة الرابط.

## خامساً: طريقة الاستخدام

- **الطفل:** يعلّم على المهام اليومية، ثم يرسم توقيعه بالقلم ويحفظه. لا يحق له تسجيل خصم أو بونص.
- **الأب:** يرى الطفلين، ويتابع ويمنح بونص 50 نقطة أو يسجل خصماً مع السبب، ويعتمد بتوقيعه.
- **الأم:** مثل الأب، بالإضافة إلى اعتماد ساعة بلايستيشن خاصة (غير نقدية).
- **الخصومات:** سجل شهري مفصل بتاريخ المخالفة وسببها وصاحب القرار وحالة القرار. عند الإلغاء لا تُمسح الواقعة، بل تُعلّم «ملغى»؛ يمكن إعادة تفعيلها.
- **التقارير:** حساب تلقائي يومي، وأسبوعي، وشهري، ومقارنة الطفلين للوالدين.
- **السقف المالي:** حتى 10 دنانير لكل طفل شهرياً؛ بونص 50 نقطة لا يرفع السقف. الصلاة 100 من 150 نقطة أساسية يومياً، ولا تخصم نقاطها المكتسبة؛ يطبق الخصم على الجزء الآخر فقط.
- **التوقيعات:** التوقيع يسجل باسم حسابه، وهو توثيق عائلي غير قانوني؛ رسم التوقيع وقيمة نقاطه غير مرتبطين بالأمان المالي.

## سادساً: مهم قبل الاعتماد النهائي

- لم يتم إنشاء مشروع Firebase أو حسابات الأسرة نيابة عنك، ولا يوجد رابط منشور حتى تنفذ الخطوات.
- المزامنة تحتاج إنترنت. قد يحتفظ المتصفح بواجهة الموقع لكن هذه النسخة ليست مصممة للعمل الكامل دون اتصال.
- قاعدة البيانات ليست بديلاً عن النسخ الاحتياطي. من Firebase Console صدّر البيانات دورياً أو استخدم آلية النسخ الاحتياطي الرسمية المتاحة ضمن خطتك.
- التوقيع على جهاز مشترك لا يغني عن الدخول بالحساب الصحيح. لا تشارك الحسابات بين الأبناء والوالدين.
- القواعد تحدد **من يحق له الكتابة**، لكن تسجيل المهام ذاتياً هو تقرير من الطفل؛ مراجعة الوالدين تحسن الموثوقية.
- كل تحديث للمهام أو تعديل بعد التوقيع لا يلغي التوقيع تلقائياً. لذلك راجعوا التغييرات الجديدة وقوموا بتحديث التوقيع عند نهاية اليوم إذا لزم.
