# نجوم البيت — Metallic Joy (Light / Dark)

هذه النسخة تضم تصميم ميتاليك فاتح ومبهج، مع خيار أعلى الصفحة لتبديل الوضع بين فاتح وداكن. الواجهة باللغة العربية والإنجليزية، وإعدادات Firebase وبيانات الأطفال كما هي.

## أسهل طريقة لتحديث GitHub
1. نزّل ملف ZIP وفك ضغطه (**Extract All**).
2. افتح: https://github.com/yelropy/nogoom-family
3. اضغط **Add file → Upload files**.
4. ارفع الملفات الموجودة داخل المجلد، وليس ملف ZIP ولا المجلد الخارجي. يجب أن يكون `index.html` في جذر المستودع، ومعه `metallic.css` و`metallic-theme.js` و`service-worker.js`.
5. إن طلب GitHub تأكيد استبدال الملفات، وافق ثم اضغط **Commit changes**.
6. افتح https://yelropy.github.io/nogoom-family/ وحدّث بـ Ctrl+Shift+R، أو افتحه في نافذة خاصة للتحقق من أحدث نسخة.

## التبديل بين الوضعين
الزر العلوي بجوار اختيار اللغة يعرض «داكن» في الوضع الفاتح، و«فاتح» في الوضع الداكن. كل جهاز يتذكر اختياره محلياً، ولا يؤثر على إعدادات الأسرة.

## ملاحظات
- لا تغيّر قواعد Firestore لمجرد تغيير التصميم.
- لا تحذف أو تعيد إنشاء حسابات الأسرة أو مستنداتها.
- هذه حزمة متكاملة تحافظ على بنود المهام، المصروف، الإشعارات، الصور، تسجيل الدخول وأيقونات PWA.
- لا يتم نسخ صور أو عناصر Novakid؛ تم ابتكار نظام ألوان ميتاليك مستقل.
- لم يتم اختبار تسجيل الدخول والمزامنة الفعلية على حساباتكم بعد رفع التحديث.
