# نجوم البيت — تحديث الملف الشخصي للأطفال

هذا التحديث مبني على نسخة **PWA** السابقة ويحافظ على Firebase، التوقيعات، اللغتين، التنبيهات، مصروف السبت، نظام النقاط والتصميم الداكن.

## الإضافة الجديدة
- تبويب **👤 ملف الطفل** للأب والأم والطفل.
- للأب والأم تعديل اسم وعمر كل طفل واختيار صورة من الهاتف أو الكمبيوتر.
- تظهر الصورة كأفاتار دائري أعلى لوحة الطفل، وتتزامن عبر Firebase بين الأجهزة.
- تُصغر الصورة تلقائياً إلى 240×240 وتُحفظ كصورة JPEG مضغوطة داخل سجل الطفل في Firestore؛ لا تحتاج Firebase Storage.
- الطفل يرى بياناته وصورته فقط، ولا يمكنه تعديلها.
- تغيير الاسم أو العمر أو الصورة لا يغيّر `kidId` أو `role` ولا يحذف سجلات النقاط.

## التثبيت على GitHub
1. افتح https://github.com/yelropy/nogoom-family
2. اختر Add file → Upload files.
3. من الحزمة ارفع `index.html`, `app.js`, `i18n.js`, `style.css`, `theme.css`, `firebase-config.js`, `service-worker.js`, `manifest.webmanifest`, `offline.html` ومجلد `icons/` إلى **جذر المشروع**. وافق على استبدال الملفات ثم Commit changes.
4. افتح Firebase Console → Firestore Database → Rules.
5. **خذ نسخة احتياطية من القواعد الحالية أولاً.** استبدل النص بالكامل بمحتوى `firestore.rules` الموجود بهذه الحزمة واضغط Publish. يلزم تحديث القواعد لإتاحة تعديل الاسم والعمر والصورة من حساب الأبوين.
6. بعد اكتمال GitHub Pages، افتح https://yelropy.github.io/nogoom-family/ وجدّد الصفحة. لو كان التطبيق مثبتاً، أغلقه تماماً وافتحه مجدداً للحصول على التحديث.

## الاستخدام
- افتح تبويب «ملف الطفل».
- اختر الطفل من القائمة أعلى الصفحة، ثم عدّل الاسم والعمر واختر الصورة.
- اضغط «حفظ الملف الشخصي»؛ الصورة والبيانات تتزامن بين أجهزة الأسرة.
- لإلغاء الصورة اضغط «إزالة الصورة» ثم «حفظ الملف الشخصي».

## تنبيهات
- الصفحة لا ترفع الصور إلى GitHub ولا تخزنها في Firebase Storage؛ الصور مضغوطة داخل سجلات `members` في Firestore وقد تُحتسب في الاستهلاك المعتاد لقاعدة البيانات.
- لا تُدخل صوراً خاصة أو حساسة دون موافقة أفراد الأسرة. قواعد Firestore تسمح بقراءة الصور للأب والأم والطفل صاحب الصورة فقط.
- لا تنشر القواعد القديمة بعد التحديث، لأنها تمنع تعديل ملفات الأطفال.
- لم يتم اختبار المزامنة فعلياً على مشروعك؛ افحصها من حساب الأب ثم جهاز الطفل قبل الاعتماد عليها.
