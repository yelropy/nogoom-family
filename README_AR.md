# نجوم البيت — نسخة تطبيق PWA للأيفون والأندرويد

## ما الذي تغير؟
- إضافة `manifest.webmanifest` لاسم التطبيق والأيقونة والتشغيل كنافذة مستقلة.
- إضافة أيقونات `icons/` لأجهزة Android وiPhone بأحجام 192 و512 و180.
- إضافة `service-worker.js` لتخزين **ملفات الواجهة الثابتة فقط**، وليس بيانات Firestore أو تسجيل الدخول. لا ندّعي العمل الكامل بدون إنترنت؛ قاعدة البيانات والمزامنة تتطلب الإنترنت.
- إضافة صفحة `offline.html` توضح للمستخدم ماذا يفعل عند انقطاع الاتصال.
- الحفاظ على ملفات `app.js`, `i18n.js`, `style.css`, `theme.css`, `firebase-config.js` من نسخة التصميم الأخيرة بدون تعديل.

## النشر على GitHub Pages — خطوة بخطوة

1. احفظ نسخة احتياطية من مستودعك الحالي إن أمكن.
2. فك الضغط عن ملف ZIP.
3. افتح https://github.com/yelropy/nogoom-family ثم اختر **Add file → Upload files**.
4. ارفع محتويات المجلد، **وليس المجلد أو ملف ZIP نفسه**. تأكد أن `index.html` و`manifest.webmanifest` و`service-worker.js` في جذر المستودع، وأن الصور داخل `icons/`.
5. اضغط **Commit changes**. يمكن ترك README_AR.md، لكن **لا ترفع `firestore.rules` إلى GitHub** (هذا الإصدار لا يحتاج أي تعديل لقواعد Firebase).
6. افتح https://yelropy.github.io/nogoom-family/ وتحقق من أن الموقع ما زال يسجّل الدخول ويتزامن بشكل صحيح.
7. إذا ظهر الإصدار القديم، جرّب إغلاق التطبيق بالكامل وإعادة فتحه، أو التحديث من المتصفح. في Chrome على الكمبيوتر: Ctrl+F5.

## تثبيت Android
- افتح https://yelropy.github.io/nogoom-family/ في Chrome.
- من قائمة ⋮ اختر **Install app / تثبيت التطبيق** (أو Add to Home screen/إضافة إلى الشاشة الرئيسية حسب الجهاز).
- سيظهر تطبيق «نجوم البيت» بأيقونته على الشاشة الرئيسية.

## تثبيت iPhone
- افتح الموقع في Safari.
- اضغط زر المشاركة ثم **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.
- لو ظهر **Open as Web App / فتح كتطبيق ويب** فعّله ثم اضغط Add.
- افتح أيقونة «نجوم البيت» من الشاشة الرئيسية.

## ملاحظات مهمة
- هذا **تطبيق ويب قابل للتثبيت (PWA)**، وليس APK/IPA أو تطبيقاً منشوراً في متجر Apple/Google.
- الحركات والتصميم الحاليان محفوظان، وكذلك دعم اللغتين وبيانات Firebase.
- **الإشعارات الموجودة حالياً داخل الموقع فقط**؛ إشعارات الهاتف عندما يكون التطبيق مغلقاً تتطلب إعداد Push Notifications منفصل.
- لا يحتفظ عامل الخدمة ببيانات المستخدمين أو API Responses أو كلمات المرور.
- ما زالت الوظائف الحساسة تتطلب اتصال الإنترنت. تم تجهيز الملفات وفحص بنيتها محلياً، لكن لا يمكن التأكيد على التثبيت والمزامنة على الأجهزة الحقيقية قبل النشر والتجربة.
